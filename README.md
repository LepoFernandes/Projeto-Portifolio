# 💻 Portfólio Lepo Fernandes

## 🚀 Sobre o projeto

Portfólio pessoal desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de apresentar meus projetos, experiências e habilidades como desenvolvedor backend em C#.
O design é responsivo e moderno, permitindo uma boa experiência em desktop e mobile.

## 🛠 Tecnologias

* HTML5
* CSS3
* JavaScript

## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Portfolio.git
   ```
2. Acesse a pasta do projeto:

   ```bash
   cd Portfolio
   ```
3. Abra o arquivo `index.html` no navegador.
